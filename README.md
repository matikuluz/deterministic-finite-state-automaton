# deterministic-finite-state-automaton

A Deterministic Finite State Automaton (DFSA) is a mathematical model used to recognize patterns in input sequences. In this repository, you'll find a simple Java implementation of a DFSA. The DFSA.java class represents the automaton, and the SystemManager.java class demonstrates how to create and use it.

## Files

1. `DFSA.java`: This Java class defines the DFSA and its core components, including the alphabet, states, transitions, start state, and final states.

2. `SystemManager.java`: This Java class serves as a sample program that creates a DFSA, defines its components, and processes an input string using the DFSA.

3. `Tuple.java`: A generic class for creating tuples (pairs) in Java, which is used in the DFSA implementation.
